## About

This list is produced by **jobbot**, a self-hosted Discord bot that searches
applicant tracking systems directly (Ashby, Greenhouse, Lever, Workday,
SmartRecruiters, Workable and ~15 more) instead of relying on job aggregators.
It de-duplicates postings across platforms, filters them down to genuine
software-engineering internships, checks each link is still live before
publishing, and posts new findings to Discord.

- **[Documentation → DOCS.md](DOCS.md)** — architecture, configuration, commands
- **[Deployment → DEPLOY.md](DEPLOY.md)** — Docker Compose, systemd, or a managed platform

Listings are filtered by location and ranked by relevance, freshness, and how
painful the application process is — quick forms rank above ones demanding an
account and six pages of re-typed résumé.
